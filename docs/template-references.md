# Report Template References

The report templates synthesize public guidance from these sources:

- ISO/IEC/IEEE 29119-3 test documentation structure: test plan, test status/completion, test design specification, test case specification, test procedure specification, test data and environment documentation.
- IEEE 829-style test plan structure: test items, features in scope/out of scope, approach, pass/fail criteria, suspension/resumption, deliverables, environment, risks, schedule, responsibilities, approvals.
- NASA requirements-change guidance: impact analysis should inspect other software parts, architecture, design, interfaces, higher/lower requirements, safety, reliability, performance, rework, new effort, stakeholders, error-introduction potential, and criticality.
- SEI regression testing guidance: changed software should be retested and regression selection should account for unmodified parts that may be damaged by the change.

These references are expressed as fixed Markdown sections rather than copied source text, so every generated report keeps a consistent professional structure.
